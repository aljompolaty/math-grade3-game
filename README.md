# 🧪 مختبر الرياضيات التفاعلي – الصف الثالث المتوسط (منهج بخت الرضا ٢٠٢٤م)

تطبيق ويب تقدمي تفاعلي (**PWA**) يغطي كامل كتاب الرياضيات للصف الثالث المتوسط بجمهورية السودان (المركز القومي للمناهج والبحث التربوي – بخت الرضا، الطبعة الأولى ٢٠٢٤م، الصفحات ١ – ٢٩٩).

---

## ✨ المميزات الرئيسية
- **تغطية شاملة للوحدات الثماني (ص ١ – ٢٩٩):** الدالة (التطبيق)، الأسس واللوغريثمات، المستوى الديكارتي والمعادلات الآنية، الدائرة (١٤ نظرية)، ضرب وتحليل المقادير الجبرية، معادلات الدرجة الثانية، الإحصاء، والحجوم.
- **٨ مختبرات هندسية وجبرية حية:** تفاعل مباشر مع الأشكال والمنقلة والمخطط السهمي وتجربة الرمل الثلاثية الأبعاد.
- **المعلم الذكي (حلّال المسائل خطوة بخطوة):** يحل المسائل المدخلة في ٣ خطوات منهجية متسلسلة مع نطق العلامات الرياضية بوضوح.
- **دفتر أخطائي الذكي:** يرصد المسائل التي أخطأ فيها الطالب ويعيد جدولتها للتدريب والعلاج.
- **شرح صوتي مدمج بصوت أ. يوسف السوداني** عبر تقنية ElevenLabs AI مع تخزين تلقائي دائم في المتصفح (`IndexedDB`).
- **قابل للتثبيت كتطبيق أندرويد (Android PWA & APK)** ويعمل بملء الشاشة وبدون إنترنت.

---

## 🚀 أولاً: خطوات الرفع على GitHub والتشغيل المباشر (في دقيقة واحدة)

1. أنشئ مستودعاً جديداً (New Repository) على حسابك في **GitHub** (مثلاً باسم `math-grade3-sudan`).
2. فكّ ضغط ملف `math-grade3-github-android.zip` وارفع جميع الملفات الموجودة بداخله إلى المستودع:
   - `index.html` (الملف الرئيسي للتشغيل المباشر)
   - `manifest.json` (ملف تعريف تطبيق الأندرويد)
   - `sw.js` (مشغّل العمل بدون إنترنت)
   - `icons/` (أيقونات تطبيق الأندرويد بدقة `192x192` و`512x512`)
   - `.nojekyll` و `.github/workflows/deploy-pages.yml`
3. من إعدادات المستودع في GitHub افتح **Settings ⟵ Pages**:
   - تحت قسم **Build and deployment** اختر **Source: Deploy from a branch** ثم اختر الفرع `main` والمجلد `/ (root)` واضغط **Save** (أو اختر **GitHub Actions** ليعمل النشر التلقائي المُرفق).
4. خلال ٣٠ ثانية سيعمل تطبيقك مباشرة على الرابط:
   `https://<اسم-حسابك>.github.io/<اسم-المستودع>/`

## 📲 ثانياً: طريقة التثبيت على هواتف الأندرويد (Android)

### الطريقة ١: التثبيت المباشر من المتصفح (بدون متجر)
1. افتح رابط التطبيق على **GitHub Pages** من متصفح **Google Chrome** على هاتف الأندرويد.
2. اضغط على زر **«📲 تثبيت التطبيق»** الموجود في أعلى شاشة التطبيق (أو من قائمة المتصفح `⋮` اختر **«تثبيت التطبيق / Install app»**).
3. ستتم إضافة أيقونة **«مختبر الرياضيات ٣م»** إلى شاشة هاتفك الرئيسية بجانب بقية تطبيقات الأندرويد، ويعمل التطبيق في وضع ملء الشاشة (`Standalone`) حتى بدون اتصال بالإنترنت.

### الطريقة ٢: استخراج ملف `.APK` لتوزيعه عبر واتساب أو تيليجرام
إذا أردت ملف تثبيت أندرويد مستقل بصيغة `.apk`:
1. بعد رفع التطبيق على GitHub Pages، انسخ رابط الصفحة.
2. ادخل إلى الموقع المجاني [PWABuilder.com](https://www.pwabuilder.com) والصق الرابط ثم اضغط **Start**.
3. اضغط **Package for stores** ثم عند خيار **Android** اضغط **Download Package** لتحصل على ملف `.apk` جاهز للتثبيت على أي هاتف أندرويد.
